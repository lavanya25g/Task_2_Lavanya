# Exploratory Data Analysis (EDA)

## Project Overview
This project explores an order dataset using Microsoft Excel to identify basic statistics, order trends, and potential outliers.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel formulas

## Analysis Performed
- Calculated total orders, mean and median order value, minimum and maximum values, and range.
- Identified potential high-value outliers using the Interquartile Range (IQR) method.
- Created a yearly order-count PivotTable and chart.
- Summarized key observations from the dataset.

## Key Findings
- Total orders analyzed: 1,200
- Mean order value: 1,053.968
- Median order value: 823.615
- Potential high-value outliers: 8
- Order counts: 510 in 2023, 459 in 2024, and 231 from January to June 2025.

## Conclusion
Excel-based exploratory analysis helped summarize order values, identify potential outliers, and examine order activity over time. The 2025 order count covers only six months and should not be compared directly with full-year totals.
